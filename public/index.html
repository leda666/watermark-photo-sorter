水印照片智能分类

v1.2.2 · PaddleOCR 系引擎 · 离线运行

程序介绍

本地离线的照片时间水印识别与归档工具：读取照片角落的日期水印（如 2026-05-08），自动按「年.月.日」建文件夹归类。全程本地运行，不上传任何照片与数据。

核心功能

  • 拖入文件夹批量识别，按日期自动归档，支持暂停 / 继续 / 停止
  • 识别引擎：PaddleOCR 系 RapidOCR-json 离线引擎，单张 0.6~1 秒，中文小字也稳
  • 灯箱纠错：大图框选日期区域直接识别，按框归类一步完成
  • 纠错学习：保存的框选区域按「图片分辨率」记忆，同尺寸照片自动复用（识别更快更准）
  • 日期约束：白名单 / 范围两种写法，只认指定日期，防误归类
  • 工作日志：实时识别日志 + 按日期本地存档（logs/ 目录），可回查可删除
  • 全程本地离线，不上传任何照片与数据

使用教程（详细版）

  • ① 基础识别：拖入照片文件夹 → 点「开始识别」。程序自动读水印日期，按「年.月.日」文件夹归类；没读出日期的进「未识别」文件夹。识别中可随时暂停 / 继续 / 停止。
  • ② 日期约束（强烈推荐）：在「日期约束」输入框填本批照片可能的日期，填完点「确认约束」（已保存，刷新不丢）。作用：只认范围内的日期，读错的数字还会自动修正到范围内，大幅减少误归类。三种写法（分隔符 . / - 均可）：
    • 单个或多个日期（白名单）：2026.5.8,2026.5.9（逗号分隔，可继续加）
    • 日期范围：2026.5.1~2026.5.10（波浪号，取首尾两天之间）
    • 混合填法也可以，点「清除」解除约束；留空 = 不限制
  • ③ 灯箱纠错（某张识别不了时）：点该照片卡片打开灯箱 → 按住鼠标拖框，框住日期所在行（框住日期文字本身，不是下面的小字）→ 点「试提取」，新引擎只识别框内区域，读出日期会自动选中 → 点「保存参数学习并归档」按该框重新识别并归类，之后同尺寸照片会自动先复用这个框（更快更准）。
  • ④ 批量补救：整批都没识别出来时，多半是水印样式特别或图片过暗——挑一张在灯箱里框选试提取，确认能读出来后，其余照片按同样方式抽查几张，剩下仍失败的直接手动归到对应日期文件夹即可。PaddleOCR 引擎下这类情况已很少见。
  • ⑤ 查日志与学习库：工作日志按日期自动存档（logs/ 目录），顶部下拉可选日期回查「为什么没识别出来」；累计学习条可展开查看/删除单条学习记录。

程序核心

RapidOCR-json 引擎（PaddleOCR PP-OCRv4 检测 + 识别模型，ONNX 离线推理，无需 Python/显卡）+ 自研日期提取（分隔符日期、紧凑日期、时间屏蔽、数字混淆修复）+ 日期约束过滤；Tesseract.js 保留为兜底引擎（引擎缺失时自动切换）。全程本地运行，单张约 0.6~1 秒。

目录与命名说明

识别成功的照片按「年.月.日」命名文件夹归档（如 2026.5.8）；「未识别」里集中放着暂时没读出日期的照片，可逐个开灯箱框选纠错。

你拖入的照片目录（源目录，结构随意）
├── IMG_001.jpg          ← 照片平铺在这里也能识别
└── 子文件夹/…           ← 有子目录也没关系

归档输出目录（识别后自动生成）
├── 2026.5.8/          ← 识别成功：按水印日期建文件夹（点分隔）
├── 2026.4.17/
└── 未识别/             ← 没读出日期的照片都在这里

程序数据（工具目录内，请勿删除）
├── learnings.json        ← 学习库：按分辨率记住框选区域 / 参数
├── engine/               ← PaddleOCR 系识别引擎（勿删，删了会退回旧引擎）
├── logs/日期.log            ← 工作日志按日期存档
└── tessdata/             ← 兜底引擎模型
